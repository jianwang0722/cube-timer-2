# WCA Rules — working summary

A practical summary of the WCA regulations this app implements. This is a
convenience reference, **not** the authority — the WCA Regulations and the
official TNoodle scrambler are. Where they and this file disagree, they win.

## Events & scrambles

Scrambles are generated by `cubing/scramble`'s `randomScrambleForEvent(eventId)`,
which implements official TNoodle behavior.

| Event | id    | Puzzle | Scramble type | Typical length                 |
| ----- | ----- | ------ | ------------- | ------------------------------ |
| 2×2   | `222` | 2x2x2  | random-state  | ~9–11 moves                    |
| 3×3   | `333` | 3x3x3  | random-state  | ~19–21 moves                   |
| 4×4   | `444` | 4x4x4  | random-state  | ~40–46 moves (SiGN wide moves) |
| 5×5   | `555` | 5x5x5  | random-moves  | ~60 moves (wide moves)         |

- **Random-state** means the scramble is derived from a uniformly random solved-
  to-scrambled state (a solver runs). **Random-moves** is a long random turn
  sequence. There is **no random-state 5×5 generator** — 5×5 (and 6×6/7×7) are
  legitimately random-moves per TNoodle. Do not "fix" this.
- 4×4/5×5 use wide-move notation (`Rw`, `Uw`, `Fw`, …) plus outer turns; the app
  shows the scramble text verbatim and the 3D preview applies the same alg, so
  what you see is exactly the state you get.
- First 4×4 generation is multi-second (solver warm-up); the app prefetches one
  scramble per event and shows a "generating scramble…" placeholder meanwhile.

## Inspection

- 15 seconds of inspection (optional; off by default).
- Audible warnings at 8s and 12s (optional).
- Starting the solve **15.00–16.99s** in → **+2**; **17.00s or later** → **DNF**.

## Penalties

- **+2**: adds 2000 ms to the recorded time **before** any average math.
- **DNF**: did-not-finish; sorts as worse than any time.

## Averages

- **mo3** (mean of 3): plain arithmetic mean; any DNF makes it DNF.
- **ao5 / ao12 / ao100** (average of N): drop the best and the worst counting
  results, then take the mean of the rest (WCA trimmed mean). A DNF counts as
  the worst; **two or more DNFs** in the window make the whole average DNF.
- Stats are per session, and each session is a single event, so all averages
  and personal bests are per-event automatically.

## Display

- Times **truncate** to centiseconds — `10.994` shows as `10.99`, never rounded
  up. Timing uses `performance.now()`.
